# Changelog

## 0.0.3 — Initial Windows-oriented version

- Added a Python implementation intended for Windows and Wireshark Extcap.
- Added FRITZ!Box challenge-response login handling.
- Added configurable router host, username, password, and capture interface.
- Added support for `--option value` and `--option=value` argument forms.
- Added Windows packaging guidance using PyInstaller.

This version has not yet been verified against a real FRITZ!Box capture session.
